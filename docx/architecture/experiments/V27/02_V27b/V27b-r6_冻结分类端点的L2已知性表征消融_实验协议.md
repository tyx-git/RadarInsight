# V27b-r6：冻结分类端点的 L2 knownness 表征消融

## 目的

V27a 已在冻结 V27 L2 的前提下验证：独立的可靠 stable8 微多普勒晚期证据
可把 parent-final accuracy 从 95.52% 提升到 96.41%，并将 Bird recall 从
92.86% 提升到 96.43%。剩余主错误不是 Bird recall，而是四个高置信
`Drone -> Bird` 误判，因此继续叠加 Drone/Bird 分类残差已由 V27b-r5
反证为无净收益。

R6 不再修改 L2 logits。它把 V27a Main epoch-20 固定为分类端点，并只检验：
完整 Liquid V2 原始轨迹是否会因加入可靠 stable8 事件摘要的因果稳定性而获得
更好的 Known/Unknown 排序。

## 两臂

| Arm | 训练输入 | 不变项 |
|---|---|---|
| `control` | 冻结 Liquid V2 raw memory、三种 innovation、gate/alpha/tau、dt/RD/物理质量事实及其因果摘要 | V27a Main logits、训练池、质量资格、头部宽度、epoch、seed |
| `stable8_treatment` | 与 control 相同，外加由 `frame_feature_reliable` 构造的因果 stable8 事件摘要、前缀均值/标准差/末次偏差、可靠覆盖与帧数量/帧覆盖事实 | 同上 |

稳定性分支不读取类别 logit、softmax、预测类别、sample id、track id、capture id、
sampling mode 或未来事件。没有可靠 stable8 帧的事件不产生摘要值；它与
`RD present` 是两种不同事实。

两个 arm 保持相同的 stable 分支容量：control 向该分支输入全零，treatment
输入可靠 stable8 事实。因此 arm 差异不能归因于额外参数量。所有覆盖率均以
当前因果前缀长度为分母，不使用完整轨迹长度。

## 标签与质量边界

- 正例：质量合格的 Drone/Bird/Balloon final parent；
- 负例：质量合格的 Unknown final parent；
- Clutter：不参与 L2 knownness 优化，只独立报告；
- 不满足 V27 确定性质量事实、可靠 stable8 覆盖数或覆盖比例的 parent：不参与
  knownness 优化，独立记为 Pending/low-quality 诊断；
- Unknown 不进入 L2 三分类、归一化、分类 loss、checkpoint 选择或 L3。

这是一个表征排序消融，不拟合 L3，也不产生部署阈值。评价仅在
`representation_development` 完成，`calibration` 留给后续独立校准。

## 主评价与晋级条件

在三个 head seed 下，分别报告 99%、97%、95% Known recall 约束下的
Unknown rejection/acceptance、AUROC、AUPRC、已知类 coverage、正确已知与
错误已知的 score 分布、Clutter 诊断和低质量 Pending 数量。

只有满足以下条件，stable8 treatment 才可进入后续 calibration/L3 工作：

1. 分类 endpoint logits 与 V27a Main 完全不变；
2. 三个 seed 中不存在明显的 Known coverage 安全退化；
3. 在至少两个 seed、且至少一个 99%/97% Known-recall 工作点，Unknown
   rejection 相对 control 有一致正向变化；
4. 收益不能来自低质量样本、Clutter 或已知分类错误被错误地计成 Unknown
   拒识成功。

若失败，结论只是当前 stable8 summary stability 表征不足；不回退为固定
softmax 阈值、单点 Mahalanobis 或新的 Drone/Bird residual。

## 已执行结果摘要

三种子已完成。`stable8_treatment` 的 AUROC 平均差为 -0.000021，故没有形成
整体排序收益；在 99% known-recall 工作点，Unknown rejection 从 28.7% 升至
41.7%（平均 +13.0pp，三个种子均为正），但在 97% 和 95% 工作点平均均为 -0.9pp。

因此 R6 仅保留为“极保守 known-recall 下的候选正信号”，不进入 calibration 或 L3。
它也没有安全拒识 V27a 的四个高置信 `Drone -> Bird` 错例；详见
[`V27b-r6_实验结果与归因.md`](V27b-r6_实验结果与归因.md)。

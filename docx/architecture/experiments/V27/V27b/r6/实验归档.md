# V27b-r6 实验归档：stable8 因果稳定性 knownness 诊断

## 实验身份

- 直接基线：冻结 V27a Main 的 raw-trajectory knownness control
- 唯一变量：增加可靠 stable8 的因果事件摘要、均值、波动、末次偏差和覆盖事实
- seeds：42、43、44
- 范围：representation development；不拟合正式 calibration/L3，不读取 test

## 结果

三 seed 平均 AUROC 从 `0.941248` 变为 `0.941227`，变化 `-0.000021`。在 `99%` overall known-recall 工作点，Unknown rejection 平均增加 `12.9630pp`；在 `97%` 和 `95%` 工作点平均均下降 `0.9259pp`。所有 bootstrap 区间跨 0。

## 正向反馈与结论

stable8 因果稳定性只在极保守工作点表现出条件性正向，不能证明整体排序或 L3 泛化改善。该变量可保留为后续 knownness 候选，但不进入默认 L3。

# V27b-r3 实验归档：条件化 Drone–Bird residual

## 实验身份

- 直接基线：冻结 V27a Main
- 唯一变量：根据冻结 L2 决策状态条件化 stable8 residual，尝试修正 Drone/Bird 边界
- 范围：known-only L2；Unknown、Clutter、L3 和 test 未暴露

## 结果与影响

Parent-final Accuracy 不变，Macro-F1 增加 `0.1615pp`，但发生 1 个 correct→wrong 与 1 个 wrong→correct，净正确数没有增加；eligible-prefix Macro-F1 下降 `0.8796pp`。

## 结论

这是错误重排而不是稳定分类提升。终态 Macro-F1 的小幅变化不足以抵消 prefix 退化，不晋级为默认分类分支。

# V27b-r5 实验归档：完整 stable8 帧序列 GRU residual

## 实验身份

- 直接基线：V27b-r4
- 唯一变量：用 event-local mask-aware GRU 读取完整 normalized stable8 frame sequence
- 固定项：V27a Main、L2 分类任务、数据边界和 Unknown 隔离

## 结果与结论

Parent-final 结果与 r4 相同：相对 V27a Accuracy 增益 `0pp`、Macro-F1 `+0.1615pp`；eligible-prefix Macro-F1 比 V27a 低 `0.9053pp`。没有净纠正已知类错误，不能作为分类改进。

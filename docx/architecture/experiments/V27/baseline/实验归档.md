# V27 baseline 实验归档

## 实验身份

- 实验：`V27 baseline`
- 类型：完整 L1/L2/L3 架构基线与工程 control
- 直接基线：V21e L1 因果航向特征、V18 stable8 L2 特征合同、自研 Liquid V2 raw-memory recurrence
- 数据：CQ08；train/validation 使用 V16 grouped index；Unknown 不进入 L1/L2 分类训练
- 当前状态：L1/L2 分类端点完成；knownness/quality/L3 registry 未完成正式拟合

## 核心变量与系统

V27 将 L1 known/background gate、L2 Drone/Bird/Balloon specialist、独立 knownness/quality heads 和 L3 语义动作合同组织为完整系统。L1、L2 的参数和 recurrent state 独立；Unknown 不是 L2 第四类。Liquid V2 保存 raw memory，LayerNorm 只用于计算和分类读出，不写回递归状态。

## 实际输出

- L1：231/232，Accuracy `99.5690%`，Macro-F1 `96.9470%`；Clutter Recall `88.8889%`。
- L2：213/223，Accuracy `95.5157%`，Macro-F1 `95.2306%`；Bird Recall `92.8571%`。
- L3 registry：`unfitted`；未校准时 fail-closed 为 `Pending/Abstain`。

## 正向反馈与影响

基线成功提供了可复核的 L1/L2 分类端点、严格 open-set 数据边界、时间策略和 L3 fail-closed 合同。这是工程层面的正向结果，但不能把基线组合中的差异单独归因于 Liquid V2。

## 结论

V27 baseline 可作为后续实验的分类和合同基座，但截至当前不能称为完成的严格开放集部署系统，也不能报告正式 Unknown 拒识或部署性能。

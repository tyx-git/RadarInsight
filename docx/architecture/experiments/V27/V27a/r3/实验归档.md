# V27a-r3 实验归档：可靠逐帧 stable8 因果证据

## 实验身份

- 直接基线：V27 baseline L2 epoch 11
- 唯一变量：增加独立的可靠 stable8 逐帧事件证据路径、因果 parent aggregation 和有界零和 late residual
- 固定项：Liquid V2 主干、原有分类器、数据 split、Unknown/Clutter 隔离
- 范围：known-only L2 分类；不拟合 L3，不评价 Unknown

## 结果

相对 V27 baseline：Accuracy `95.5157% → 96.4126%`，Macro-F1 `95.2306% → 96.1436%`，Bird Recall `92.8571% → 96.4286%`。混淆矩阵由 `[[109,4,0],[3,52,1],[1,1,52]]` 变为 `[[109,4,0],[1,54,1],[1,1,52]]`，净纠正 2 个 Bird→Drone，未增加其他终态错误。

## 正向反馈与结论

这是 V27 系列当前最明确的已知类分类正向结果。它支持“独立逐帧微多普勒证据路径能够补充已有 stable8 汇总”的判断，但不支持 Unknown 拒识、L3 或部署收益；V27a 原始 paired report 当前缺失，Main 结果由后续冻结 control 和 checkpoint 交叉确认。

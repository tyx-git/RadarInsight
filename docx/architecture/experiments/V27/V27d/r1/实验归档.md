# V27d-r1 实验归档：冻结端点与校准人口修正 control

## 实验身份

- 直接基线：V27 baseline L1 epoch14、V27a Main L2 epoch20
- 唯一变量：在冻结分类端点上接入独立 knownness/quality heads、确定性质量 eligibility 和动态 L3 校准流程
- seed：42；数据：CQ08 的 representation_fit、representation_development、calibration
- Unknown 不进入 L1/L2 分类；正式 test、OOF、跨源和部署未执行

## 实际结果

- L1 knownness development AUROC `0.896356`；L2 knownness development AUROC `0.933173`。
- L1/L2 quality head 可运行，但 L1 负例 support 很小，不能作为稳定泛化证明。
- calibration Unknown support 只有 `15`，低于正式要求 `100`。
- L1 risk-constrained 选择不可行，最高最小已知目标 route recall 约 `0.904545`；L2 最高最小类 route recall 约 `0.909091`，均低于 `0.98` 安全线。
- registry 为 `unavailable`，没有活动阈值；L3 全部 fail-closed 为 `PENDING_ABSTAIN`。

## 正向反馈与结论

r1 的正向价值是建立了可运行的完整三层 control、正确隔离 Unknown、明确质量与校准失败时的 Pending 语义。它没有产生可计入的 Unknown 拒识提升，也不具备正式 conformal/deployment 资格。当前首要瓶颈是校准 Unknown support 不足和 knownness 风险约束不可行，而不是简单增大模型容量。

# V27d-r13 实验归档：raw envelope modulation profile shape

## 实验身份

- 直接基线：冻结 V27a Main epoch20
- 唯一变量：接入此前未使用的 `envelope_modulation_profiles` 64-bin profile shape，并构造 causal current/mean/std/delta branch
- seeds：42、44；Liquid V2、基础 L1/L2、knownness、quality、L3 均不改变
- 范围：known-only L2 分类；Unknown/L3/deployment/test 未执行

## 结果

Seed42 Accuracy 从 `96.41%` 降至 `95.07%`，总正确数减少 `3`；seed44 降至 `94.62%`，总正确数减少 `4`。两个 seed 都新增 Drone→Bird 和 Bird→Drone，未产生 wrong→correct；平均 Accuracy 下降约 `1.57pp`。

## 结论

原始 envelope profile 可以被严格接入，但在当前闭集 parent-final residual 目标下不能可靠转化为分类收益，反而稳定损害 Drone、Bird 和 Balloon 指标。不能据此断言原始微多普勒形状无信息；应停止扩大同一 residual 容量，不接入默认 L2/L3。

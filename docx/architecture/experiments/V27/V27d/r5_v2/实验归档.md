# V27d-r5_v2 实验归档：Bird-route 前缀一致性目标

## 实验身份

- 直接基线：V27d-r5 control
- 唯一变量：加入 Bird 正例前缀一致性与 Bird-route Unknown terminal uplift 训练目标
- seed：42；分类端点冻结；正式 L3/conformal/deployment/test 未执行

## 结果

Development Unknown rejection 与 control 相同，均 `12.50%`；calibration Unknown rejection 与 control 相同，均 `8.33%`。Calibration Bird recall 保持 `100%`，但没有拒识增益；AUROC 低于 r5 control。合格 Bird-route Unknown support 只有 `12`。

## 结论

前缀一致性目标未产生拒识提升，判定为失败，不晋级 L3 或部署。不能继续在当前小规模 Unknown 池上把同类损失微调包装成开放集能力。

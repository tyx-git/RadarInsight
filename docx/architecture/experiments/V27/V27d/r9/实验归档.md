# V27d-r9 实验归档：高维 causal Doppler profile shape

## 实验身份

- 直接基线：冻结 V27a Main
- 唯一变量：将 181-bin residual Doppler profile 的当前 shape、running mean/std 和相邻差分接入 Drone/Bird pair residual
- seeds：42、44；Liquid V2、L1/L2 endpoint、L3 和 Unknown 均不改变

## 结果

Seed42 Accuracy `92.3767%`、Bird Recall `91.0714%`；seed44 Accuracy `90.5830%`、Bird Recall `85.7143%`。相对冻结基线分别少正确 `9` 和 `13` 个 parent，residual 大量饱和，train accuracy 为 `100%` 而 validation 明显下降。

## 结论

高维 profile 分支在当前容量和训练预算下明显过拟合，不能据此判定 Doppler shape 本身无信息，但该结构停止晋级。不得接入 L3 或部署。

# V27d-r6 实验归档：GRU 与 Liquid V2 Bird verifier 比较

## 实验身份

- 直接基线：V27d-r5 control
- 唯一变量：Bird-route verifier 的递归核心，GRU 与 Liquid V2 对比
- seeds：42、43、44；两臂均为 64 维递归核心、参数量相同
- 分类端点冻结；Unknown 不作为 L2 类别；正式 L3/deployment/test 关闭

## 结果

Development Liquid 平均 Bird precision `81.47% ± 1.63pp`，false-positive rejection `25.00% ± 8.27pp`；calibration Bird precision `77.72% ± 0.19pp`，false-positive rejection `16.67%`。相对 GRU 的 calibration precision 平均增益仅 `0.75pp`，且不具备三 seed 同方向稳定性。

## 结论

Liquid verifier 在部分 seed/development 指标上有利，但未稳定优于 GRU，不替换默认 verifier，也不能形成正式 L3 结论。主要限制仍是 Bird-route Unknown support 仅 `12`。

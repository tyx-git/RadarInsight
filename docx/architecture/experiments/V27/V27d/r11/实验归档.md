# V27d-r11 实验归档：full stable8 causal shape projection

## 实验身份

- 直接基线：同 seed 的 V27d-r6 Liquid treatment
- 唯一变量：32 维 stable8 当前值、causal running mean/std 和上一有效事件差分进入 knownness readout
- seeds：42、44；Liquid core、分类端点和 r6 base readout 冻结

## 结果

Development false-positive rejection 相对 r6 平均提升 `9.375pp`，但 calibration Unknown rejection 两个 seed 均保持 `2/12=16.667%`；seed44 calibration 额外拒绝一个 Bird，AUROC 下降约 `0.42pp`。正式 L3 support 不足。

## 结论

r11 证明 shape branch 能改变 development 排序，但不能迁移到 calibration 动作边界；不接入默认 knownness 或 L3。

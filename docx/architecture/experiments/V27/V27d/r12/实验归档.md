# V27d-r12 实验归档：causal prefix P25 聚合

## 实验身份

- 直接基线：同 seed 的 V27d-r6 Liquid treatment
- 唯一变量：将最终 knownness 分数由最后有效事件改为 eligible causal prefix 分数的 P25
- seeds：42、44；分类端点、质量 eligibility、padding 和 prefix mask 冻结

## 结果

Calibration Unknown rejection 从 `2/12=16.67%` 提升到 `3/12=25.00%`，但两个 seed 的 Bird recall 均由 `98.11%` 降至 `96.23%`，低于产品安全线；AUROC 平均下降约 `6.45pp`。新增拒识还包含一个 Drone route negative。

## 结论

P25 暴露了部分 Bird-like Unknown，但以已知类安全和整体排序为代价，不能作为独立硬 gate，也不计为可部署 Unknown 能力。判定 `diagnostic_only_no_promotion`。

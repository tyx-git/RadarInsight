# V27c-r23 实验归档：TR robust clipping × causal motion 2×2

## 实验身份

- 直接基线：V27c-r22 的 matched L2 重训思路
- 唯一研究问题：在 `legacy/robust clipping × zero/causal motion` 四臂中分离 clipping、motion 和交互效应
- seeds：42、43
- 范围：known-only L2；Unknown、Clutter、knownness、quality、L3 和 test 未暴露

## 结果

同一 seed 内四个 arm 的离散预测完全一致。motion 主效应、clipping 主效应和交互项的 Accuracy、Macro-F1、Balanced Accuracy 均为 `0`。motion 和 clipping 会改变连续 logits，但没有 argmax 翻转。验证集实际受 clipping 影响的事件很少，不能把 clipping 写成分类改善。

## 结论

r23 未证明 causal motion 或 robust clipping 改善当前 known-only L2 分类。clipping 仍可作为数值安全候选，但若继续研究应改用连续稳定性、quality 或 knownness 作为预注册终点。

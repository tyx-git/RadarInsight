# V27 系列逐实验归档总表

## 归档范围

本总表整理 `src-v3/v27` 中截至 `V27d-r13` 的实验包。`V27d-r14`、`V27d-r15` 及其产物不纳入本归档。

目录规则为：

```text
experiments/V27/<实验系列>/r<编号>/实验归档.md
```

例如：`V27d-r13` 的归档位置为 `experiments/V27/V27d/r13/实验归档.md`。

## 判定口径

- **正向反馈**只指在同一冻结基座、同一评价口径下由变量产生的可归因收益。
- 训练重跑、seed 波动、局部子群高分和连续 logits 变化不能单独写成分类收益。
- `known-only` 实验不能推出 Unknown 拒识、L3 或部署能力。
- `Pending/Abstain` 不计为 Unknown 拒识成功。
- `contract smoke` 只证明工程合同通过，不证明泛化性能。

## 关键累计结论

1. V27a-r3 是当前最明确的已知类分类正向结果，但其证据边界仍是 known-only L2 分类。
2. V27b-r6 及 V27d-r5–r12 的开放集方向多次出现 development 局部信号，但没有在当前小规模 Bird-route calibration 池上形成稳定可迁移收益。
3. V27c 的 motion 系列没有证明 motion 对当前 L2 离散分类有可归因提升；r22/r23 的更高绝对分数属于重训/seed 或共同 arm 变化。
4. V27d-r9–r13 说明新增微多普勒形状分支需要任务匹配、低容量和独立校准，不能直接通过闭集 residual 叠加获得可靠收益。
5. 截至 r13，V27 没有完成可用于论文部署声明的 OOF、跨源、独立正式 L3 和 test 闭环。

# V27 系列实验归档总表

## 归档范围

本总表整理 `src-v3/v27` 中的 V27a、V27b、V27c、V27d 系列实验。V27d-r17 至 r21 使用 Excel 数据源，标题以 `[E]` 标注，并作为重要转折子实验单独保存。

每个实验系列只保留一个 `实验归档.md`；系列内部的 `r1`、`r2` 等仅作为子实验行保存，不再建立独立归档目录或文件。

早期 `00_基线` 和 `01_V27a` 文档继续作为历史协议与架构材料保留，但此前生成的 V27 baseline、V27a 简式归档记录已撤回，不列入本表。

## 判定口径

- 正向反馈只指在同一冻结基座、同一评价口径下由变量产生的可归因收益。
- 训练重跑、seed 波动、局部子群高分和连续 logits 变化不能单独写成分类收益。
- `known-only` 实验不能推出 Unknown 拒识、L3 或部署能力。
- `Pending/Abstain` 不计为 Unknown 拒识成功。
- `contract smoke` 只证明工程合同通过，不证明泛化性能。

## 累计结论

1. V27b 的 stable8 表征与 knownness 变量未形成可迁移的默认模型收益。
2. V27c 的 motion 系列和 clipping × motion 试验没有证明当前 L2 离散分类得到提升。
3. V27d 的 Bird-route knownness 与 Doppler/profile 分支未形成稳定的开放集或分类收益，部分分支反而造成已知类退化。
4. 截至 `V27d-r21`，V27 尚未完成可用于论文部署声明的正式 OOF、跨源验证、独立 L3 和 test 闭环；r17–r21 的 Excel 结果属于 TR-only 或输入消融诊断。

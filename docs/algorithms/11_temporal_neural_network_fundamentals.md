# 11. 时序神经网络基础：为什么轨迹分支要建模“随时间变化”

## 轨迹不是一张表，而是一段过程

项目里的轨迹数据不是静态属性集合，而是目标在时间上的连续运动记录。

同一个目标在不同时间点会表现出：

- 速度变化
- 加速度变化
- 方向变化
- 抖动强弱变化
- 停走或持续运动模式

所以轨迹建模的核心不是“某一时刻是什么”，而是“这段时间里是怎么变化的”。

## 为什么普通全连接网络不够

如果把一整段轨迹直接摊平成一个大向量喂给全连接层，会有两个问题：

- 时间顺序信息很容易丢掉。
- 很难显式建模前后时刻之间的关系。

但时序模型天生就是为这个问题准备的。

## 常见时序模型怎么理解

### RNN / GRU / LSTM

这类模型会一步一步读序列，前面的状态会影响后面的状态。

优点是直观，缺点是：

- 序列长了不够稳。
- 并行效率一般。
- 对局部模式和长时依赖的兼顾不一定够好。

### TCN

TCN 可以理解成“时序版卷积网络”。

它擅长：

- 抓局部时间模式
- 并行计算
- 用膨胀卷积扩大时间感受野

例如：

- 一小段突发加速
- 一段持续抖动
- 短时间内的速度摆动

### Transformer

Transformer 的核心不是按顺序一步步记，而是直接去看“哪些时间点彼此相关”。

它更擅长：

- 长时依赖
- 全局关系建模
- 找关键时刻

## 为什么项目里是 `Residual TCN + Transformer`

因为两者互补。

### `Residual TCN`

它先解决局部时间模式问题：

- 快速速度起伏
- 小范围方向波动
- 连续几帧的轨迹抖动

### `Transformer Encoder`

它再往上看更全局的规律：

- 这一整段轨迹更像盘旋还是直飞
- 哪些时间段最能代表目标行为
- 局部模式之间如何组合成整体行为

### `Attention Pooling`

最后不是简单平均所有时刻，而是让模型自己学会：

- 哪些时间片更重要
- 哪些时间片更有代表性

## 轨迹分支为什么现在相对成熟

因为它不只是一个模型骨架，还配了比较完整的特征工程。

当前派生特征包括：

- `delta_range_m`
- `delta_azimuth_deg`
- `speed_delta_mps`
- `acceleration_mps2`
- `turn_rate_degps`
- `range_jitter_m`
- `snr_delta_db`

这些特征已经把很多运动学信息显式交给模型了。

# 17. 复数信号、IQ 和 `real / imag`：为什么不能太早丢掉相位

## 为什么雷达数据里会有复数

很多初学者第一次看到雷达数据时，会问：

- 为什么不是普通实数矩阵？
- 为什么会有复数？

原因是雷达信号里不仅有“大小”，还有“相位”。

而复数正好适合同时表示这两部分信息。

## 什么是 IQ

IQ 可以粗略理解成：

- `I`：同相分量
- `Q`：正交分量

它们一起构成一个复数表示。

所以在工程里，复数信号并不神秘，本质上就是：

- 一路表示一个方向的分量
- 一路表示与它正交的另一个分量

## 幅度和相位分别代表什么

对于一个复数信号，可以从两个角度看：

### 幅度 `Magnitude`

幅度更像“能量大小”。

### 相位 `Phase`

相位更像“这个信号在周期中的位置”。

很多时候，两个信号幅度差不多，但相位关系完全不同。

这也是为什么“只看幅度”会损失信息。

## 为什么本项目要保留 `real / imag`

当前默认 `6` 通道里，前两个就是：

- `real`
- `imag`

这样做的意义是：

- 不在数据预处理阶段就把复数信息压扁
- 让后面的网络自己学习哪些复数结构更有价值

从工程角度看，这是一种更保守也更稳的做法。

## 为什么不直接只存幅度图

如果太早只保留幅度：

- 相位相关信息会丢掉
- 某些时间变化模式会变得不明显
- 后面的模型只能在不完整信息上学习

对于微动识别来说，这种信息损失可能会影响上限。

## 为什么当前默认没有把相位相关通道放进前 6 个

项目里曾经做过更丰富的复数感知实验，例如相位变化和相干性相关通道。

但当前默认主路径最终保留的是更稳的一版：

- `real`
- `imag`
- `log amplitude`
- `temporal difference`
- `background suppressed`
- `local contrast`

原因不是相位信息无用，而是：

- 真实数据规模有限时，越复杂的输入不一定越稳
- 当前主路径优先追求鲁棒和可复现

## `real / imag` 和后续 CNN 的关系

把 `real / imag` 直接作为输入后，CNN 看到的就不是简单灰度图，而是：

- 复数结构在两个通道上的展开
- 再结合幅度、时间差分、背景抑制和局部对比
- 一起进入时空主干

这能让模型从更完整的底层信息开始学习。

## 一个直观类比

可以把“只保留幅度”理解成：

- 你只保留了声音有多大
- 却丢掉了波形相位关系

而“保留 `real / imag`”更像：

- 你把信号的更完整结构保留下来了
- 再让模型自己判断什么最有用

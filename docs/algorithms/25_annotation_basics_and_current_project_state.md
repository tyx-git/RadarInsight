# 25. 标注基础：当前项目的数据集是怎么标注的

## 当前项目现在的标签到底怎么来

当前项目里，最基础的类别标签并不是人工逐帧点出来的，而是：

- 从原始 `.mat` 文件名中提取
- 再在 `prepare-pro` 流程里标准化成训练可读的标签

当前主要标准类别是：

- `Bird`
- `RotaryDrone`
- `FixedWing`

也就是说，**当前项目现在用的是 session 级弱监督标签**。

## 什么叫 session 级弱监督标签

可以简单理解成：

- 一个 session 对应一个总体类别
- 这个 session 下切出来的很多 clip，会继承这个类别
- 但没有做到“每一帧、每一小段都由人工单独确认”

所以它和高质量精标数据集不是一回事。

## 当前标签落到哪些文件里

在标准 session 目录里，和标签最相关的文件主要有：

- `labels/labels_trackclip.jsonl`
- `labels/labels_matched.jsonl`

其中：

- `labels_trackclip.jsonl` 更像样本切片记录
- `labels_matched.jsonl` 更像训练标签落地文件

## 为什么说它还不是高质量数据集

因为高质量数据集至少要解决：

- 标签是否足够细
- 标签是否足够准
- 标注标准是否统一
- 是否存在不确定样本的处理规则
- 是否有人工复核

而当前项目的标签虽然能训练模型，但本质上仍然是：

- 从文件名得到的粗粒度标签
- 适合当前阶段训练
- 不等于精细标注数据集

## 常见标注粒度

### 1. Session 级标注

一个 session 一个标签。成本最低，但粒度最粗。

### 2. Track 级标注

一条轨迹一个标签。比 session 更细，但轨迹内部仍可能存在局部片段不稳定。

### 3. Clip 级标注

一小段时间窗一个标签。对当前项目来说，这是最值得追求的粒度。

### 4. Frame 级标注

每一帧单独标注。最细，但成本最高。

## 对当前项目来说最值得升级到哪一层

如果从“成本 / 收益比”来看，当前项目最值得追求的是：

- **clip 级精细标注**

因为当前模型训练本来就是按 clip 读样本。


当前项目已经有标签，但它们主要是 session 级弱监督标签；如果你想做高质量数据集，下一步重点应放在 clip 级精细标注。

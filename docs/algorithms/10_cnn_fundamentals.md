# 10. 卷积神经网络基础：为什么 RD 分支离不开 CNN

## 先把卷积想简单一点

卷积可以先理解成：

**用一个小窗口在整张图上来回滑动，专门找某一种局部模式。**

这个局部模式可能是：

- 一条边
- 一个小亮点
- 一段条纹
- 某种局部纹理

在本项目里，这些局部模式就可能对应：

- 微动谐波条纹
- 多普勒侧带
- 局部能量峰
- 被背景抬高或压低后的细小结构

## 为什么 RD 图适合用 CNN

因为 RD 图本质上也是二维结构：

- 一维是距离轴
- 一维是多普勒轴

在这张图里，目标类别的区别往往表现成局部结构差异，而 CNN 最擅长的就是找局部结构。

例如：

- 鸟类可能出现更不稳定、更碎的微动纹理。
- 旋翼无人机可能更容易形成相对规则的周期性结构。
- 固定翼目标可能在谱图上呈现另一类更稳定的能量分布。

## 为什么不是只用一层卷积

一层卷积通常只能看到非常局部的模式。

深层 CNN 的意义是逐层扩大感受野：

- 前几层看局部纹理。
- 中间层看局部结构之间的组合。
- 后几层看更高层的目标模式。

这和人看图的过程很像：

- 先看到一些细节。
- 再把这些细节拼起来。
- 最后形成“这是鸟还是无人机”的判断。

## 为什么项目里用的是 3D CNN，而不是普通 2D CNN

因为项目输入的不是单张 RD 图，而是一个 RD clip 序列。

也就是说，模型看到的是：

- 时间维
- 距离维
- 多普勒维

所以当前 RD 主干不是只看一帧，而是同时看：

- 一帧长什么样
- 相邻帧怎么变化
- 这些变化是否构成持续的微动模式

这就是 3D CNN 的价值。

## 卷积核在本项目里到底学什么

可以把卷积核理解成很多不同的“探测器”：

- 有的探测器专门看短条纹。
- 有的探测器专门看局部高亮块。
- 有的探测器专门看时间方向上的变化。
- 有的探测器专门看多普勒轴上的周期结构。

经过训练后，这些卷积核会自动学会对分类有帮助的局部结构。

## 为什么要加残差结构

随着网络变深，训练会变难。

残差连接的作用可以粗暴理解成：

- 如果新层学不到更好的东西，至少别把原来的信息破坏掉。

它让深网络更容易训练，也让特征传递更稳定。

## 为什么 CNN 还不够，前面还要做 RD 强建模

因为通用 CNN 很强，但它不知道“多普勒轴在物理上意味着什么”。

所以项目又在 CNN 前面加了：

- `RadarMicroMotionEnhancer`
- `SpectralAxisRefiner`
- `BackgroundContrastRefiner`

这相当于先把更像微动的线索强化出来，再交给 CNN 去做更深层的时空编码。

- `src/models/cnn_encoder.py`
- `src/training/dataset.py`


CNN 在这个项目里不是单纯“看图片”，而是负责从 RD 时空序列里自动提取对分类最有用的局部微动模式。

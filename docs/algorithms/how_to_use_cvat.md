# 如何使用 CVAT 进行标注

## 这篇文档适合谁

这篇文档面向第一次接触 `CVAT` 的同学。目标不是把 `CVAT` 的所有功能都讲一遍，而是告诉你：

- `CVAT` 在当前项目里到底用来做什么
- 为什么不能直接把 `.mat` 或 `.h5` 扔进去标注
- 你应该如何把 RD clip 导出成 `CVAT` 能识别的格式
- 在 `CVAT` 里具体该怎么创建任务、怎么标、怎么导出

如果你以前从没用过 `CVAT`，先完整读完这篇，再开始实际操作。

## 1. 什么是 CVAT

`CVAT` 的全称是 `Computer Vision Annotation Tool`，本质上是一个网页标注平台。

它最常用于：

- 图片分类标注
- 目标框标注
- 分割标注
- 视频目标跟踪标注

在当前项目里，我们主要把它当成：

> 一个用来给 RD clip 做人工审核与人工标注的可视化工具。

也就是说，它不是雷达信号处理工具，而是**标注工具**。

## 2. 为什么不能直接标 `.mat` / `.h5`

这是很多人第一次会问的问题。

答案很简单：

- `CVAT` 面向的是图像和视频数据
- 但当前项目里的原始数据是 `.mat`、`.h5`、`CSV` 这样的工程格式

例如：

- `TR.mat`：轨迹来源数据
- `RD.mat / DPL`：频谱来源数据
- `rd_data.h5`：项目内部生成的 RD 主数据
- `rd_clips.h5`：项目内部生成的 RD clip 数据

这些都不是 `CVAT` 能直接打开的格式。

所以正确流程一定是：

```text
.mat / .h5
    -> 导出成图片序列或短视频
    -> 导入 CVAT
    -> 进行人工标注或复核
    -> 导出标注结果
    -> 再转换回项目内部标签格式
```

## 3. 在当前项目里，CVAT 具体标什么

当前项目的核心目标不是普通目标检测，而是雷达识别。

所以在 `CVAT` 里，你最常做的事情不是画框，而是：

- 看一段 RD clip 是不是可判
- 给这一段 clip 赋一个类别标签
- 记录是否不确定
- 记录是否需要复核

也就是说，最适合当前项目的用法通常是：

- **分类标注**
- **片段级审核**
- **疑难样本复核**

## 4. 标注前要准备什么

在把数据导入 `CVAT` 之前，你至少要准备三样东西。

### 1）可视化素材

`CVAT` 需要的是：

- 图片序列
- 或视频文件

所以你要先把：

- `rd_clips.h5`

导出成：

- 一组 `.png`
- 或一个 `.mp4`

### 2）标签方案

你要先确定当前任务允许哪些类别。

例如：

- `Bird`
- `FixedWing`
- `RotaryDrone`
- `Other`
- `Unknown`

如果标签体系没定好，后面标注的人很容易各标各的。

### 3）命名和映射关系

你必须知道：

- 一张图或一段视频对应哪个 `session`
- 对应哪个 `sample_id`
- 后面怎么把标注结果映射回项目内部文件

否则就会出现“标完了，但不知道写回哪里”的情况。

## 5. 在 CVAT 里推荐怎么建项目

一般建议按下面顺序来。

### 第一步：创建 Project

Project 是一个大的标注容器。

你可以为当前雷达项目单独建一个，例如：

- `RadarInsight_RD_Annotation`

这样以后不同任务都归到同一个项目里，管理更清晰。

### 第二步：定义 Labels

创建 Project 或 Task 时，先定义标签。

建议最少包含：

- `Bird`
- `FixedWing`
- `RotaryDrone`
- `Other`
- `Unknown`

为什么要有 `Unknown`？

因为在真实数据里，一定会有一些片段：

- 微动太弱
- 背景太重
- 目标不完整

这类片段如果被强行标到某一类，反而会污染数据集。

### 第三步：加属性（可选，但很推荐）

除了类别本身，建议再加几个辅助属性，例如：

- `confidence`：`high / medium / low`
- `needs_review`：`yes / no`
- `visibility`：`clear / weak / noisy`

这样后面做复核和筛选时会更方便。

## 6. Task、Job、Project 分别是什么

这是初学者很容易混的地方。

### Project

最大的管理单位。

相当于一个总项目。

### Task

一个具体标注任务。

例如：

- 某 200 个 RD clip 的人工标注

### Job

Task 被平台进一步切出来的工作单元。

如果一个 Task 很大，`CVAT` 会自动分 Job 给不同标注者或复核者。

一句话：

- Project 管总任务
- Task 管一批数据
- Job 管具体执行片段

## 7. 当前项目里推荐怎么导入数据

### 方案 A：导入图片序列

适合：

- 每个 clip 导出成若干帧图片

优点：

- 简单直观
- 一帧一帧看得清楚

缺点：

- 文件会很多

### 方案 B：导入短视频

适合：

- 每个 clip 导出成一个小视频

优点：

- 时间连续性更强
- 更适合看微动变化

缺点：

- 需要提前把帧序列编码成视频

对当前项目而言，如果目的是判断一个 clip 的类别，通常**短视频更适合**。

## 8. 在 CVAT 里到底怎么标

如果当前任务是 clip 级分类，通常有两种思路。

### 方案 1：把整段 clip 当成一个分类任务

你在看完整段 clip 后，给它打一个类别标签。

这是当前项目最推荐的方式之一。

### 方案 2：按帧逐帧加标签

这种方式更细，但工作量也更大。

如果当前只是做：

- clip 级精标
- 或疑难样本审核

一般没必要一帧一帧都标。

## 9. 新手实际操作顺序

给你一个最实用的顺序：

### 1）打开任务

进入某个 `Task` 或 `Job`。

### 2）先播放完整 clip

不要一上来就急着标。

先看完整段，判断：

- 目标是不是清楚
- 微动是否稳定
- 背景是不是太重

### 3）判断是否可判

先问自己：

- 我能稳定判断它是什么吗？

如果不能，优先使用：

- `Unknown`
- 或 `needs_review = yes`

### 4）再打标签

只有当你确定时，再选：

- `Bird`
- `FixedWing`
- `RotaryDrone`

### 5）补属性

例如：

- `confidence = high`
- `needs_review = no`

### 6）保存并进入下一条

## 10. 标完之后怎么导出

在 `CVAT` 里完成标注后，要做两步：

### 第一步：导出标注结果

导出成 `CVAT` 支持的格式，例如：

- `CVAT for images`
- `CVAT for video`
- `COCO`（如果你后面要自己做转换）

### 第二步：映射回项目内部格式

这一步才是当前项目真正需要的。

因为训练代码不是直接吃 `CVAT` 原始导出格式，而是更偏项目化的：

- `labels_trackclip.jsonl`
- `labels_matched.jsonl`

所以你最终还是要把 `CVAT` 导出的结果转换成当前项目内部可以识别的标签结构。

## 11. 新手最容易犯的错误

### 错误 1：标签体系没定好就开标

这会导致后面：

- 同一类被不同人标成不同名字
- `Other` 和 `Unknown` 混用

### 错误 2：把不可判样本强行标成某一类

这会直接污染数据集。

### 错误 3：不保留 `sample_id / session_id` 映射关系

这样你后面根本没法把标注结果写回项目。

### 错误 4：只标，不复核

高质量数据集不是“标完就结束”，而是：

- 标注
- 复核
- 修订

## 12. 在当前项目里，怎么把 CVAT 用好

真正高价值的用法不是“全量依赖 CVAT 自动产出最终训练集”，而是：

- 用 `CVAT` 做高质量人工审核
- 用 `CVAT` 给关键 clip 做精标
- 用 `CVAT` 复核模型容易混淆的样本

例如：

- `FixedWing` 和 `RotaryDrone` 经常混淆
- 那就把这类高价值样本优先导出到 `CVAT` 标注和复核

这样效率最高，也最符合当前项目迭代阶段。

## 最后总结

在当前项目里，`CVAT` 不是用来直接处理 `.mat / .h5` 的，而是：

- 先把 RD clip 导出成图片或视频
- 再用 `CVAT` 做人工标注和复核
- 再把结果转换回项目内部标签格式

一句话：

> `CVAT` 是当前项目通往高质量人工标注的重要桥梁，但它只负责“看和标”，不负责直接读雷达工程数据。

# 28. 本项目推荐的标注工作流：从弱标签走向高质量数据集

## 为什么你现在会觉得“数据集还是模糊”

因为当前项目已经有一条可训练链路，但这条链路的标签本质上还是：

- session 级弱监督标签

这意味着：

- 它已经能支撑当前模型训练
- 但如果你想把数据集做成真正高质量、可长期复用的资产，就必须把标注流程再往前推进一步

## 本项目最推荐的标注升级路线

```text
文件名弱标签
-> 标准 session 构建
-> RD clip 可视化导出
-> clip 级人工精标
-> 复核与裁决
-> 生成高质量标签文件
-> 再扩大规模
```

## 为什么最推荐 clip 级

因为当前模型训练本身就是按 clip 进行的，所以 clip 级标签最匹配当前训练单元。

## 一个推荐的推进顺序

### 第一步

继续用当前链路生成标准 session：

- `prepare-pro`

### 第二步

选出最值得精标的一批 session：

- 类别均衡
- 难度有层次
- 数据质量较好

### 第三步

导出 RD clip 可视化结果，进入人工标注平台。

### 第四步

做 clip 级标签和复核。

### 第五步

把人工标签转换回项目训练格式。

### 第六步

重新训练，并和弱标签版本对比。

## 当前最应该先做的事

如果你现在就要迈向高质量数据集，最推荐先做的是：

- **定义一份正式的 clip 级标注规范文档**

因为没有规范，后面的人工标注很容易越来越乱。


当前项目的最佳升级方向，不是把弱标签直接丢掉，而是把它当起点，逐步升级成 clip 级高质量精标数据集。

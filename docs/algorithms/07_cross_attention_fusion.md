# 07. 双向 Cross-Attention 融合

## 为什么需要融合

当前模型同时有两种模态：

- 轨迹模态：宏观行为
- RD 模态：微动特征

如果只是简单拼接，它们之间其实没有真正“交流”。

## 当前为什么使用双向 Cross-Attention

因为当前目标是高精度，而高精度融合通常不是把两个向量接起来就结束，而是让它们互相解释。

当前做法是：

- 轨迹 token 去查询 RD token
- RD token 再反向查询轨迹 token

这样做的意义是：

- 轨迹可以告诉 RD：当前行为上下文是什么
- RD 可以告诉轨迹：当前微动细节是什么

## 你可以怎么理解它

把它想成两个专家互相提问：

- 轨迹专家：我看到这个目标运动得像无人机，但微动上是不是也支持这个判断？
- RD 专家：我看到这里有微动纹理，但轨迹上是不是合理？

这样最后的融合结果就比单独看任意一个模态更稳。

## 为什么它比门控拼接强

门控拼接只能做“加权”，但 Cross-Attention 能做“交互”。

这就是高精度版本保留它的原因。

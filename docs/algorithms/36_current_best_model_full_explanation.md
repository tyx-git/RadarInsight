# 当前最优模型全讲解
## 为什么要读这篇文档
这篇文档专门讲当前项目里“效果最好、结构最完整”的模型路线，目标不是只告诉你模块名，而是让你真正明白：这个模型为什么这样设计、每一部分在解决什么问题、它是怎么一步步从早期 baseline 演化成当前最优版本的。如果你是初学者，读完这篇文档后，至少应该能回答这些问题：什么是轨迹分支，什么是 RD 分支，为什么要做双分支融合，为什么要做层级分类，为什么还要做后处理校准，当前模型的创新点到底在哪里。
## 当前最优模型一句话概括
当前最优模型本质上是一个“双分支雷达目标识别模型”：一条分支看轨迹时序数据，学习目标的宏观运动规律；另一条分支看 RD 微动数据，学习目标的微动纹理和时频结构；然后通过跨模态融合、粗细粒度分层分类和组内校准，把两路信息合成最终结果。简单说，它不是“只靠 CNN 看图”，也不是“只靠时序网络看轨迹”，而是同时利用目标“怎么运动”和“在雷达谱图里长什么样”这两类信息。
## 整条链路是怎么走的
项目当前的主链路是：`pro/raw -> prepare-pro -> pro/sessions -> data/sessions -> train -> evaluate -> report`。`pro/raw` 里是雷达信号处理后的真实 `.mat` 文件，分成 `TR` 和 `RD` 两类。`TR` 主要提供轨迹相关信息，比如距离、速度、方位、SNR 等；`RD` 文件里核心是复数 `DPL` 数据，后续会经过 `DPL -> RD` 的处理链生成可供模型使用的微动输入。`prepare-pro` 的作用就是把这些原始数据整理成统一标准的 `session` 结构，写入 `pro/sessions` 和 `data/sessions`。训练阶段真正读取的是 `data/sessions`，也就是说，模型不会直接吃原始 `.mat`，而是吃标准化后的 session 数据集。
## 什么是当前最优模型里的输入样本
一个真正送进模型的样本，不是一个完整 session，而是从 session 里切出来的一个 clip。这个 clip 同时包含三类信息：第一类是轨迹序列，也就是一段时间内目标的距离、方位、速度等变化；第二类是 RD clip，也就是同一时间窗内对应的距离-多普勒微动张量；第三类是标签。也就是说，当前模型学的不是“一个大文件属于什么类”，而是“一个具体时间片段内，这个目标表现出什么类别特征”。这样做的好处是样本数量更多，时序局部行为和微动局部模式也更容易被模型捕捉到。
## 轨迹分支到底学什么
轨迹分支要解决的问题是：目标在宏观运动层面上表现出什么规律。比如某个目标是不是速度更高、更平稳、更单调、更像持续巡航，而另一个目标是不是变化更碎、更抖动、更像局部机动。轨迹分支不仅看原始量，还看派生量。原始量包括 `range_m`、`azimuth_deg`、`radial_speed_mps`、`snr_db` 等；派生量包括 `delta_range_m`、`delta_azimuth_deg`、`speed_delta_mps`、`acceleration_mps2`、`turn_rate_degps`、`jerk_mps3` 等。这些派生特征的作用，是把“目标在变化”这件事显式交给模型，而不是全靠模型自己从原始数值里慢慢猜。
轨迹分支内部不是一个简单的 RNN，而是“局部时序建模 + 长程依赖建模”的组合。前半部分用 `Residual TCN` 去抓局部变化模式，比如短时速度波动、局部转向、连续加速减速；后半部分用 `Transformer` 去看更长范围内的依赖，比如一段轨迹前后是否一致、是否存在长期稳定飞行结构。这样设计的好处是，模型既能看近处的细节变化，也能看远处的整体规律。
## 为什么轨迹分支还要有全局物理摘要
如果轨迹分支只看归一化后的局部序列，很容易学到“变化形状”，却丢掉绝对物理量级。可是在雷达目标识别里，绝对速度水平、速度跨度、距离跨度、方向一致性这些信息很重要。比如固定翼目标在很多情况下会体现出更高、更稳定的绝对速度层级，而旋翼目标可能在速度分布和方向一致性上表现不同。所以项目后期给轨迹分支增加了全局物理摘要特征，例如 `clip_range_mean_m`、`clip_range_span_m`、`clip_speed_mean_mps`、`clip_speed_span_mps`、`clip_abs_speed_mean_mps`、`clip_speed_direction_consistency`、`clip_range_monotonicity` 等。这些特征不是替代时序分支，而是作为对时序分支的修正和补充，让模型既理解“怎么变”，也理解“绝对处在什么层级”。
## RD 分支到底学什么
RD 分支的任务是看雷达微动特征。它关注的是：目标在距离-多普勒空间里呈现出什么样的纹理、局部结构和时间变化。轨迹分支更像看“这个目标怎么飞”，而 RD 分支更像看“这个目标在谱图里长什么样”。比如，某些目标在微动结构上会更稳定、谐波更明显、局部对比更强，或者在对称性和时序演化上体现出不同模式。RD 分支并不是简单吃一张图，而是吃一个“有时间维的谱图张量”，因此它能够同时学习每一帧内部的空间结构和多帧之间的时间变化。
## 从 DPL 到 RD 为什么很关键
项目里 `RD` 文件内部核心并不是现成的标准 RD 图，而是复数 `DPL` 数据。因此，真正高质量的识别，不只取决于神经网络有多强，还取决于前面的 `DPL -> RD` 链做得好不好。这个链路现在已经不只是“做一次 FFT 就结束”，而是逐渐加入了窗函数、杂波抑制、微动增强、目标对齐和 ROI 裁剪。原因很简单：如果输入的 RD 表示本身就不稳定、目标位置经常偏、背景太重、能量中心不准，那后面模型再强也只是学错的东西。所以当前最优模型的一个关键进步，就是把 RD 链路从“能跑通”升级成“更稳定、更可学”。
## 为什么 RD 分支不只看局部，还看全局
项目前期一个大问题是：如果只裁局部 ROI，裁偏了就会丢信息；如果只看整幅 RD，又容易把背景和杂波一起学进去。后来主链路升级成双视角 RD：一条是目标对齐后的局部 ROI，另一条是全局上下文。局部视角帮助模型聚焦目标本身的微动结构，全局视角帮助模型理解更大的谱图背景，避免因为局部裁剪过紧而误判。可以把它理解成：局部视角负责“盯着目标看”，全局视角负责“知道目标在整体环境里的位置和周围情况”。这一步是当前最优模型的重要升级点之一。
## 为什么 RD 输入不是单通道图像
当前最优模型已经不再使用单通道幅度图，而是使用多通道 RD 表示。它包含实部、虚部、对数幅度、时间差分、局部对比、对称多普勒视图，以及全局上下文通道等。这样做的原因是：不同通道描述的是同一目标的不同侧面。实部和虚部保留了复数信息，对数幅度强调能量结构，时间差分强调变化，局部对比强调局部纹理，对称多普勒视图帮助削弱“接近/远离方向”这种可能误导类别判断的符号因素。全局上下文通道则补充了更宽的背景信息。也就是说，当前 RD 分支看到的不是“一张图”，而是一组互补的雷达微动表示。
## RD 主干为什么用 X3D-M 风格 3D CNN
RD 分支当前主干采用的是 `X3D-M` 风格 3D CNN，而不是简单 2D CNN。原因在于：RD 输入同时具有空间结构和时间结构。2D CNN 只能看单帧内部的空间关系，而 3D CNN 可以同时看空间和时间，把“局部微动纹理”和“这些纹理如何随时间演化”一起建模。`X3D-M` 风格主干的优点是，它在参数规模、表达能力和工程可控性之间取得了相对平衡。它不算极轻量，但也没有重到完全不可控，尤其适合当前这个既要看时间、又要看 RD 微动结构的任务。
## 为什么不是简单拼接，而是跨模态融合
当前最优模型不是把轨迹特征和 RD 特征简单拼接后丢给一个全连接层，而是使用了双向 `Cross-Attention` 融合。简单拼接的问题是：两种模态之间没有显式交互，模型只能在最后自己猜“哪一部分更有用”。跨模态注意力的好处在于：轨迹分支可以主动去“询问”RD 分支，RD 分支也可以反过来利用轨迹信息。这样，融合不再是“把两个向量堆起来”，而是“让两个模态互相对齐、互相补充”。对于雷达识别这种多模态任务，这个设计明显比简单拼接更合理。
## 为什么后来还要加模态可靠性门控
即使做了跨模态注意力，仍然存在一个问题：并不是每个样本里轨迹和 RD 都同样可靠。有的样本轨迹很清晰但 RD 噪声大，有的样本 RD 微动结构很明显但轨迹质量一般。如果模型始终固定地信任某一模态，就容易在某些样本上犯系统性错误。因此，后期给融合层加入了模态可靠性门控，让模型可以为轨迹分支和 RD 分支分别估计“我现在有多可信”，然后再决定融合时更偏向谁。这一步的本质，不是换模型骨架，而是让模型学会“什么时候该更信轨迹，什么时候该更信 RD”。
## 为什么输出头要变成层级分类
随着实验深入，项目发现很多错误并不是“Bird 和 AircraftTarget 混了”，而是“同一粗类内部的细分类边界不好分”。例如 `FixedWing` 和 `RotaryDrone` 都属于更大的“航空目标”粗类，它们的大类差别没有 `Bird` 和飞机那么大。于是当前最优模型把输出头改成了层级分类：先预测粗类，再做细分类。粗分类头帮助模型先学会“大方向上分清生物目标和航空目标”，细分类头再进一步去区分 `FixedWing` 和 `RotaryDrone`。这比一开始就强迫模型在所有类别上做同等难度的直接分类更稳，也更符合未来扩展到 `5` 大类、`20+` 子类的方向。
## 细分类头为什么又换成了余弦分类器
在后期实验里，单纯的线性细分类头虽然能工作，但在同一粗类内部的边界上仍然不够强。于是项目把细分类头换成了余弦分类器。余弦分类器的核心思想是：让模型更关注不同类别特征在特征空间中的“方向差异”，而不只是简单的线性打分。这种方式对细粒度区分往往更有效，尤其适合像 `FixedWing` 和 `RotaryDrone` 这种“看起来相似，但边界很细”的情况。它不是为当前小数据集硬写的技巧，而是一种对未来大规模多子类任务同样合理的通用设计。
## 为什么还要有细边界损失
仅仅有细分类头还不够，因为同一粗类内部的类别仍可能挤在一起。于是训练时又引入了细边界损失，目的就是把同一粗类内部不同细类的表示主动拉开。你可以把它理解成：除了要求模型分类正确，还要求模型在特征空间里“把相近类尽量分得更开”。这一步对解决 `FixedWing` 和 `RotaryDrone` 的边界问题尤其关键，因为这两类不是完全不同的大类，而是容易互相混淆的近邻类。
## 为什么训练结束后还要做组内校准
当前最优模型还有一个很重要的后处理步骤，就是验证集驱动的组内 logit 校准。它的意义在于：有时候模型已经学到了足够好的特征，但最终决策阈值仍然存在偏置。比如模型可能总是更偏向把模糊的航空目标判成 `RotaryDrone`。这时候，与其大改整个模型，不如在验证集上学习一个小的组内偏置，对同一粗类内部的类别 logits 做轻量修正。这样做的好处是：成本低、风险小、很适合 CPU 平台，而且往往能在不重新训练的前提下继续把精度往上推。
## 当前最优模型为什么能达到现在的效果
当前最优效果并不是来自某一个“神奇模块”，而是来自整条链路的一系列升级叠加。第一，数据从伪数据切换到真实雷达 `.mat`。第二，数据切分从随机 clip 切分升级成严格的 `session` 切分，减少数据泄漏。第三，`DPL -> RD` 处理链逐步增强。第四，启用目标对齐 ROI 裁剪。第五，RD 分支从单视角升级成局部 ROI + 全局上下文双视角。第六，轨迹分支加入了更丰富的动态特征和全局物理摘要。第七，融合层加入模态可靠性门控。第八，分类头升级成粗细分层结构。第九，细分类头升级成余弦分类器。第十，再通过组内校准去修正剩余的阈值偏置。也就是说，当前最优模型是“整套系统共同变好”的结果，而不是单一网络层数增加的结果。
## 当前最优模型的真正创新点是什么
真正的创新点不在于“用了深度学习”，而在于把雷达识别问题拆成了几个本质层面，并在每一层上做了更合理的设计。第一，轨迹和 RD 双分支，把宏观运动和微动纹理同时纳入。第二，RD 双视角，让模型既看局部目标，又看全局上下文。第三，模态可靠性门控，让融合不是固定权重。第四，层级分类，让粗类和细类分开学。第五，余弦细分类头，让组内细边界更清楚。第六，组内校准，让后处理不只是简单阈值，而是面向粗类内部决策偏置的轻量修正。这些创新点拼在一起，才构成了当前最优路线。
## 当前最优模型还存在哪些限制
尽管当前最优结果已经明显提升，但它还不是项目的终点。首先，当前数据集仍然是样例规模，不是最终 `3万+`、`5` 大类、`20+` 子类的目标数据集。其次，虽然 `Bird` 和 `FixedWing` 已明显改善，但同一粗类内部的边界未来在更大数据集上仍可能重新变复杂。再次，RD 链路虽然已经很强，但后续在更大数据规模和更复杂目标类型上，可能还需要更强的微动表示。也就是说，当前最优模型应当理解为“已经很强的阶段性最优主线”，而不是最终上限。
## 初学者最该记住的五件事
如果你读到这里还是觉得信息很多，那就先记住五件事。第一，这个项目不是单模态模型，而是轨迹 + RD 双分支模型。第二，轨迹分支负责学宏观运动规律，RD 分支负责学微动和谱图结构。第三，融合不是简单拼接，而是带跨模态交互和可靠性控制。第四，输出不是单层分类，而是粗类 + 细类分层决策。第五，当前最优结果来自整条链路的不断修正，而不是某一个模块单独“神奇变强”。只要先记住这五点，再回头看代码和训练结果，你就不会迷失。
